# Babel

Aprenda idiomas jogando. Um jogo no navegador, sem instalação, para estudar **inglês, espanhol, francês, italiano e russo** a partir do português.

## Como funciona

- **Mapa de fases:** cada idioma tem 8 unidades (o russo tem 9, começando pelo alfabeto cirílico). Cada unidade tem 3 lições e um baú de recompensa.
- **Exercícios variados:** palavra nova, escolher a tradução, ouvir e escolher, formar pares, montar frases com peças e escrever a resposta.
- **XP e níveis:** cada acerto vale XP, com bônus de combo para acertos seguidos. Os níveis vão de Turista a Lenda de Babel.
- **Vidas:** cada erro numa lição custa 1 vida. Uma vida volta a cada 30 minutos, e um treino completo devolve 1.
- **Sequência de dias, meta diária e missões do dia.**
- **Moedas e loja:** recarga de vidas, protetor de sequência e XP em dobro.
- **21 conquistas.**
- **Treino com repetição espaçada:** as palavras que você mais erra voltam com mais frequência.

A pronúncia usa as vozes do próprio navegador. Chrome e Edge costumam ter vozes para todos os idiomas.

## Atalhos

- `1` a `4`: escolhem uma opção
- `Enter`: verifica a resposta ou continua
- `Backspace`: remove a última palavra ao montar uma frase
- `Esc`: sai da lição

## Onde ficam os dados

Seu progresso fica salvo no `localStorage` do navegador. Nada é enviado para nenhum servidor.

## Adicionar conteúdo

Todo o vocabulário está em `data.js`. Para incluir uma unidade, palavras ou um idioma novo, siga o formato descrito no topo do arquivo.
